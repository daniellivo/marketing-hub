## 📋 Checklist Pre-Publicación (Listicle)

### Estructura de Lista
- [ ] Número de items en título coincide con items en contenido
- [ ] Cada item tiene estructura consistente (mismas secciones)
- [ ] Items están ordenados lógicamente (mejor a peor, o criterio claro)
- [ ] Justificación clara de por qué cada item está en su posición
- [ ] Tabla comparativa al final resume todos los items

### Contenido por Item
- [ ] Cada item tiene imagen representativa
- [ ] Explicación clara de qué es el item (no asume conocimiento)
- [ ] Pros Y contras balanceados (no solo pros)
- [ ] Información de precio/inversión incluida
- [ ] "Mejor para" especifica perfil ideal de usuario
- [ ] Ejemplo real o caso de uso concreto
- [ ] Pasos de "cómo empezar" accionables

### SEO para Listicles
- [ ] Número en título es exacto (no "9+" ni "casi 10", usar número preciso)
- [ ] Keywords "mejores", "top", "lista de" en título y URL
- [ ] Cada item es un H2 con formato "[Número] [Nombre del Item]"
- [ ] Anchor links permiten saltar a items específicos
- [ ] Meta description menciona número de items y beneficio principal

### GEO para Listicles
- [ ] Intro explica criterios de selección objetivos
- [ ] Tabla comparativa extractable como snippet
- [ ] "Guía de decisión rápida" con condicionales claros
- [ ] FAQ incluye "¿Cuál es la mejor para [caso específico]?"
- [ ] Cada item puede ser citado independientemente

### Comparabilidad
- [ ] Tabla comparativa lado a lado incluida
- [ ] Criterios de comparación son objetivos y medibles
- [ ] "Guía de decisión rápida" con escenarios if-then
- [ ] Menciones honoríficas para opciones que casi entraron
- [ ] Explicación de por qué opciones populares NO están en la lista (si aplica)

### Actualización y Mantenimiento
- [ ] Fecha de última actualización visible
- [ ] Fecha de próxima revisión planificada
- [ ] Sección de "Novedades [Año]" si es actualización
- [ ] Metodología de selección transparente
- [ ] Disclosure sobre afiliaciones/bias (si aplica)

### Engagement y Compartibilidad
- [ ] Intro con estadística o declaración compartible
- [ ] Infografía o imagen resumen de la lista
- [ ] CTAs para compartir en redes sociales
- [ ] Formato escaneablede (bullets, negritas, íconos)
- [ ] Navegación rápida al inicio para saltar a items

### Livo-Específico

- [ ] CTA conecta naturalmente con problema que resuelve Livo

## 💡 Consejos para Usar Este Template

1. **Número impar funciona mejor**: Listas de 5, 7, 9 items tienden a performar mejor que números pares. Evita listas muy largas (+15 items).

2. **Orden estratégico**:
   - Puedes ordenar de mejor a peor (tradicional)
   - O poner un item muy bueno al inicio, otro al final (para retención)
   - O agrupar por categorías con subsecciones

3. **Cada item debe ser sustancial**: Mínimo 150-200 palabras por item. Si no puedes escribir tanto, tu lista es muy larga.

4. **Tabla comparativa es crítica**: Muchos lectores saltarán directo ahí. Debe ser completa y entendible independiente del resto del artículo.

5. **Actualiza regularmente**: Listicles se vuelven obsoletos rápido. Marca en calendario revisar cada 3-6 meses.

6. **Sé honesto con contras**: Listas que solo tienen pros pierden credibilidad. Incluye contras reales.

7. **Testing A/B del número**: Si no estás seguro del número óptimo de items, prueba con variaciones (ej: "7 vs 9").
