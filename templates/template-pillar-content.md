## 📋 Checklist Pre-Publicación

Antes de marcar el artículo como "listo para revisión", verifica:

### SEO
- [ ] Keyword principal en: title, H1, primer párrafo, URL, meta description
- [ ] Keywords secundarias distribuidas naturalmente (2-3% densidad)
- [ ] H2s y H3s optimizados con keywords long-tail
- [ ] Meta description de 150-160 caracteres
- [ ] URL slug limpio y descriptivo
- [ ] Alt text en todas las imágenes con keywords relevantes
- [ ] Enlaces internos a 3+ artículos relacionados
- [ ] Enlaces externos a 2-3 fuentes autoritativas

### GEO (AI Optimization)
- [ ] Resumen ejecutivo al inicio para AI snippets
- [ ] Preguntas/respuestas estructuradas (FAQ con schema)
- [ ] Datos específicos y citables (estadísticas, métricas)
- [ ] Definiciones claras y autoritativas
- [ ] Listas con bullets para extracción fácil
- [ ] Structured data (JSON-LD) para FAQPage
- [ ] Citas con evidencia y fuentes creíbles

### Contenido
- [ ] Introducción con hook emocional/estadística impactante
- [ ] Tabla de contenidos con anchor links
- [ ] Ejemplos concretos del sector sanitario

### Tono y Voz Livo

- [ ] Claro y directo (sin jerga innecesaria)
- [ ] Transparente (datos reales, no exageraciones)

## 💡 Consejos para Usar Este Template

1. **No llenes todo mecánicamente**: Adapta secciones según el tema. No todos los pillar content necesitan 3 fases de implementación o 3 tendencias futuras.

2. **Prioriza calidad sobre longitud**: Si un pilar se explica bien en 200 palabras, no lo estires a 500.

3. **Datos > Opiniones**: Cada claim importante debe tener una fuente, estadística o ejemplo concreto.

4. **CTA naturales**: Los CTAs a productos Livo deben sentirse orgánicos al contenido, no banners publicitarios forzados.

5. **Actualiza fechas**: Pillar content es "evergreen" pero debe actualizarse cada 6-12 meses. Marca fecha de última actualización.

6. **Interlinking estratégico**: Este tipo de contenido debe enlazar a artículos satélite (how-to, listicles) y recibir enlaces de ellos.
